# 🎬 CineScope

**ทุกความสำเร็จของหนัง มีตัวเลขเล่าเรื่อง**

เว็บแอปสำหรับโปรเจกต์กลุ่มวิชา Data Tools หัวข้อ **"ปัจจัยที่ส่งผลต่อความสำเร็จของภาพยนตร์ ปี 1980–2020"**
ใช้ชุดข้อมูล Movie Industry (`movies.csv` 7,668 เรื่อง 15 คอลัมน์) วัดความสำเร็จ 2 ด้าน คือ **รายได้ (gross)** และ **คะแนนผู้ชม (score)**

เว็บนี้อ่าน เพิ่ม แก้ไข และลบข้อมูลในไฟล์ Excel (`data/movies.xlsx`) จริง และหน้าวิเคราะห์ข้อมูลแสดงผลที่กลุ่มคำนวณด้วย **Analysis ToolPak ของ Excel** ในไฟล์เดียวกัน ส่วนตัวเลขในหน้าแรก Dashboard และ Simulator คำนวณใหม่จากชีต `movies` ทุกครั้ง

## วิธีติดตั้งและรัน

ต้องมี **Python 3.10 ขึ้นไป** · เว็บใช้งานได้โดยไม่ต้องต่ออินเทอร์เน็ต (ฟอนต์อยู่ในโปรเจกต์แล้ว) ยกเว้นหน้า Dashboard ที่ต้องโหลดจาก Tableau Public

```bash
cd movie-project
pip install -r requirements.txt
python app.py
```

## ตั้งค่ารายชื่อกลุ่มและลิงก์ Tableau

ค่าทั้งหมดอยู่ด้านบนของไฟล์ `app.py`

**รายชื่อกลุ่ม** (แสดงใน footer ทุกหน้า) เก็บไว้ในตัวแปร `GROUP` ตัวเดียว

```python
GROUP = {
    "name": "CineScope",
    "members": [
        "นางสาว วนิดา พิทักษ์วัฒนานนท์ 67050499",

    ],

```

**ลิงก์ Tableau Public** (แสดงในหน้า Dashboard) เก็บไว้ในตัวแปร `TABLEAU_URL`

1. เปิดไฟล์ `.twbx` ใน Tableau แล้วเลือก **File → Save to Tableau Public**
2. เปิด Dashboard บนเว็บ Tableau Public กด **Share** แล้วคัดลอกลิงก์
3. วางลิงก์ใน `app.py`

```python

```

ใช้ได้ทั้งลิงก์แบบ `/views/…` และ `/app/profile/…/viz/…` ระบบจะแปลงเป็นลิงก์สำหรับฝังให้เอง ถ้ายังไม่ใส่ลิงก์ หน้า Dashboard จะแสดงขั้นตอนนี้แทนหน้าว่าง

**ข้อควรระวัง**

- **อย่าเปิด `movies.xlsx` ค้างไว้ขณะใช้เว็บ** ถ้าเปิดอยู่ เว็บจะบันทึกไม่ได้ (ขึ้นข้อความเตือน) ให้ปิดเว็บก่อนเปิดไฟล์ไปรัน ToolPak

- **ถ้ารัน ToolPak ใหม่** คอลัมน์ในชีต `movies` เรียงตามแบบของเว็บ (`id`, `name`, `rating`, `genre`, `year`, `release_date`, `release_country`, `score`, ...) ให้เลือกช่วงข้อมูลตามชื่อคอลัมน์
- บันทึกแต่ละครั้งใช้เวลาประมาณ 2 วินาที เพราะต้องเขียนทั้งไฟล์เพื่อรักษาชีตผลวิเคราะห์ไว้

## การจัดการข้อมูลและไฟล์ Excel

- **คอลัมน์ `id`**: เพิ่มเลขไม่ซ้ำให้ทุกแถว ใช้อ้างอิงตอนแก้ไขและลบ
- **เรท**: รวม `Unrated` เข้ากับ `Not Rated` เป็นกลุ่มเดียว
- **วันฉาย**: แยกคอลัมน์ `released` เช่น `June 13, 1980 (United States)` เป็น `release_date` (`1980-06-13`) และ `release_country` (`United States`) แถวที่มีแค่เดือน/ปี เช่น `November 1980` จะเก็บตามเดิม ไม่เดาวันที่เอง
- **ค่าว่าง**: ไม่ลบแถวที่ไม่มี budget แต่การคำนวณด้านการเงิน (Profit, ROI, regression) ใช้เฉพาะแถวที่มีทั้ง budget และ gross
- **Profit และ ROI**: คำนวณใหม่ทุกครั้งที่โหลดข้อมูล (`Profit = gross − budget`, `ROI = gross ÷ budget`) ไม่ได้เก็บลงไฟล์
- **บันทึกอย่างปลอดภัย**: ทุกการเพิ่ม แก้ไข ลบ จะเขียนลงไฟล์ชั่วคราว `movies.tmp.xlsx` ก่อน แล้วจึงแทนที่ไฟล์เดิม ไฟล์จึงไม่เสียแม้บันทึกไม่สำเร็จ
- **ไฟล์ถูกเปิดค้าง**: ถ้าเปิด `movies.xlsx` ใน Excel อยู่จนบันทึกไม่ได้ เว็บจะแจ้งเป็นภาษาไทยให้ปิดไฟล์ก่อน และไม่ทิ้งข้อมูลที่กรอกไว้

## หลักการของโมเดลใน Simulator

ใช้ **Multiple Linear Regression** คำนวณด้วย numpy (`numpy.linalg.lstsq` วิธี least squares) ไม่ใช้ scikit-learn

**โมเดลรายได้**

```
log(gross) = b0 + b1·log(budget) + b2·runtime + b3·year + (dummy ของประเภทหนัง)
```

- ใช้ log เพราะทั้งรายได้และทุนสร้างเบ้ขวามาก (หนังไม่กี่เรื่องทำเงินมหาศาล) b1 จึงอ่านได้ว่า "ทุนสร้างเพิ่ม 1% รายได้คาดการณ์เพิ่มประมาณ b1%"
- สร้างจากหนังที่มีทั้ง budget และ gross
- **ช่วงที่เป็นไปได้** คือช่วงที่หนังจริงครึ่งหนึ่งตกอยู่ (เปอร์เซ็นไทล์ที่ 25–75 ของค่าคลาดเคลื่อนของโมเดล)

**โมเดลคะแนน**

```
score = c0 + c1·runtime + c2·year + (dummy ของประเภทหนัง)
```

**รายละเอียดอื่น**

- **ประเภทหนัง**: ใช้เฉพาะประเภทที่มีหนังอย่างน้อย 30 เรื่อง ประเภทที่พบบ่อยที่สุดเป็นฐาน (baseline) และประเภทอื่นได้ dummy คนละตัว
- **ROI และกำไรที่คาดการณ์**: `ROI = รายได้ที่คาดการณ์ ÷ ทุนสร้าง`
  - BLOCKBUSTER เมื่อ ROI ≥ 3
  - HIT เมื่อ ROI ≥ 1.5
  - BREAK EVEN เมื่อ ROI ≥ 1
  - FLOP เมื่อต่ำกว่า 1
- **หนังจริงที่ใกล้เคียง 5 เรื่อง**: เลือกจากประเภทเดียวกันที่ทุนสร้างใกล้กันที่สุด (วัดระยะบนสเกล log) โดยให้หนังเรทเดียวกันได้ลำดับก่อน และใช้ปีที่ใกล้กันเป็นตัวตัดสินเมื่อเสมอกัน
- **เรท**: ใช้เลือกหนังเปรียบเทียบเท่านั้น ไม่ได้เป็นตัวแปรในโมเดล ตามสูตรที่กำหนดไว้ข้างบน
- **สร้างโมเดลใหม่อัตโนมัติ**: เมื่อไฟล์ Excel เปลี่ยน (ตรวจจากเวลาแก้ไขไฟล์) ผลจึงเปลี่ยนตามข้อมูลที่เพิ่มหรือแก้
- หน้า Simulator มีส่วน "หลักการของโมเดล" ที่แสดงค่า R², จำนวนข้อมูล และผลของแต่ละตัวแปรจากข้อมูลปัจจุบัน

> ผลลัพธ์เป็นการประมาณจากข้อมูลในอดีต ไม่ใช่การทำนายที่แม่นยำ โมเดลไม่รู้ปัจจัยสำคัญอย่างนักแสดง เนื้อเรื่อง การตลาด หรือคู่แข่งในช่วงฉาย และตัวเลขเงินไม่ได้ปรับตามเงินเฟ้อ

- **แอนิเมชัน**: ถ้าตั้งค่าเครื่องให้ลดการเคลื่อนไหว (`prefers-reduced-motion`) เว็บจะข้ามแอนิเมชันและแสดงผลทันที
